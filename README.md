# E-Commerce Sales & Customer Behavior Analysis

## Project Overview
This project analyses online retail transactions using Python to understand sales performance, product demand, customer behaviour, and geographical revenue distribution.

## Dataset
- **Source:** UCI Machine Learning Repository
- **Dataset:** Online Retail
- **Records:** 541,909 original rows
- **Columns:** 8
- **Period:** December 2010 – December 2011

Dataset link: https://archive.ics.uci.edu/dataset/352/online+retail

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Data cleaning and missing-value analysis
- Duplicate detection
- Product revenue and quantity analysis
- Country-wise sales analysis
- Monthly revenue and demand trends
- Average order value calculation
- Customer revenue analysis
- Outlier investigation
- Cancellation analysis
- Correlation analysis
- Data visualization

## Key Findings
1. The United Kingdom was the leading market, generating approximately 9.00 million in recorded revenue.
2. PAPER CRAFT, LITTLE BIRDIE recorded the highest quantity sold, at 80,995 units.
3. November 2011 recorded the highest monthly revenue.
4. Average order value was 533.17, while median order value was 303.30.
5. Customer 14646 generated the highest recorded customer revenue, at 280,206.02.
6. Cancelled invoice numbers represented 15.69% of unique invoice numbers under the project's definition.
7. Unit price and quantity had a Pearson correlation of -0.0038.

## Business Recommendations
- Focus on retaining high-value customers.
- Explore growth opportunities outside the UK.
- Plan inventory and promotions around seasonal demand patterns.
- Investigate cancellations and returns.
- Separate postage and service charges from merchandise revenue.

## Limitations
- December 2011 contains only partial-month data.
- Missing customer IDs limit customer-level analysis.
- Extreme transactions may influence statistical summaries.
- The analysis describes patterns and does not prove causation.
